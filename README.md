🛠️ Aegon Blender Addon Pack Technical Descriptions Aegon UV Tools (v7.0.0):

Aegon UVW Box Map: Applies textures onto objects with a single click using the box mapping method, ensuring no stretching. 📦

Perfect Align (Active): Perfectly aligns all selected faces to the UV coordinates of the last selected (active) face, matching both position and rotation. 🎯

Smart UV Stack (Experimental AI): Analyzes faces in the scene based on geometric similarities (vertex count and perimeter length) and automatically stacks identical parts to save texture space. 🧠

Aegon Texture Exporter V2:

Converts textures in the scene into the professional game engine format, .dds. 🖼️

Supports multi-threading to export hundreds of textures in seconds. ⚡

Provides a secure workflow with automatic naming rules and a pre-process backup system. 🛡️

Aegon Material Optimizer:

Deduplication: Thanks to its hash-based system, it detects identical image files with different names and merges them into a single file, reducing memory (RAM/VRAM) usage. 📉

YTD-Ready: Automatically performs naming and cleaning processes suitable for the texture dictionary (YTD) structure required for FiveM (GTA V). ✅

Aegon Poly Optimizer:

Reduces unnecessary polygon counts without compromising the visual quality of the objects. 📉

Makes models high-performance (high FPS friendly) for in-game use with triangulation and edge reduction tools. 🚀

Aegon Texture & UV Fixer:

Finds lost textures in the scene, cleans empty material slots, and automatically repairs missing UV nodes. 🔍

Clears incorrect shading (auto smooth) on models and optimizes texture settings (Spec/Roughness). ✨
